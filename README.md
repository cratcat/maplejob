# 픽셀 히어로즈: 상어 보스

GitHub Pages에서 바로 실행되는 HTML5 Canvas 횡스크롤 액션 게임입니다.

## 실행
1. ZIP 압축을 풉니다.
2. 저장소 루트에 `index.html`, `style.css`, `game.js`, `README.md`를 업로드합니다.
3. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch** → `main` → `/(root)` → **Save**를 선택합니다.
5. 몇 분 뒤 Pages에 표시되는 URL에서 플레이합니다.

로컬 테스트는 `index.html`을 브라우저로 열면 됩니다. 별도 빌드나 서버가 필요하지 않습니다.

## 조작
- `A / D` 또는 `← / →`: 좌우 이동
- `W / S` 또는 `↑ / ↓`: 2.5D 레인(깊이) 이동
- `Space`: 점프
- `J`: 기본 공격
- `K`: 특수 공격
- `1`–`4`: 영웅 변경

## 게임 요소
- 플레이어: 칼통, 당근 전사, 디스코 피자맨, 의자 괴물
- 몬스터: 리본 돼지, 애벌래, 나쁜 졸라맨, 대형 공룡, 아기 상어 보스
- 처치 보상: 골드와 회복 아이템 드롭
- 공룡은 일반 몬스터보다 크게 표시되며 체력과 공격력이 높습니다.
- 보스는 몬스터 10마리 처치 후 등장합니다.

## 그래픽 및 라이선스
캐릭터와 배경은 `game.js`의 Canvas 벡터 도형으로 직접 그려집니다. 외부 이미지 파일이나 유료 에셋을 사용하지 않으며, 게임이 외부 이미지 URL에 의존하지 않도록 구성했습니다. Google Fonts는 네트워크 연결 시 글꼴을 가져오며, 연결이 안 되어도 대체 글꼴로 동작합니다.

## 커스터마이징
- 밸런스/체력/골드: `game.js` 상단의 `heroes`, `enemyTypes`
- 시각 효과: `drawHero()`, `drawEnemy()`, `drawBackground()`
- 화면 색상/레이아웃: `style.css`
